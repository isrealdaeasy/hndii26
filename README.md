# Digital Portfolio Website

This project is a responsive digital portfolio website built with HTML, CSS, and JavaScript. It includes an About section, Skills section, and dynamically generated Projects section with at least three project cards.

## Features

- Responsive single-page portfolio layout
- About, Skills, and Projects sections
- Dynamic project rendering with JavaScript
- Interactive dark mode toggle
- Mobile-friendly design

## Project Structure

- `index.html` – main portfolio page
- `styles.css` – site styling and responsive layout
- `script.js` – dynamic project rendering and theme toggle

## Local Preview

Open `index.html` in a browser to view the website locally.

## Deployment

This project is intended for deployment with GitHub Pages from the repository root.
